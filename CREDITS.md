# Engine, Audio & Media Attributions (*Un Dimanche sur la Seine · 塞纳河畔的星期日*)

## Animation Engine
- Built on [**CodePaint-Engine**](https://github.com/yiggeror/CodePaint-Engine) (`anim.core`, `anim.time`, `anim.paint.engine`, `anim.paint.world3`, `anim.paint.light`, `anim.audio`, `anim.output`).
- All visual imagery is 100% procedurally painted in 3D world coordinates (no pre-rendered images, no 3D mesh assets, no generative AI pixels).
