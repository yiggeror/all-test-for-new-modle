# Gate 2 · 四季 11 秒循环审看

四条均为 1920×1080、30 fps、22 秒，画面由 320×180 原生像素按 6× 最近邻放大。每条含两个完整的 330 帧周期，11.000 秒是核查接缝的位置。页面上的 MP4 是标准 H.264 High 兼容审看版；精确逐像素检查用同源无损原件。

## 无损原件

在仓库目录运行下面一条命令。可离线恢复四份未经重压的 1080p MP4，脚本逐片校验，并验证每个完整视频的 SHA‑256：

```sh
python previews/gate_2/tools/restore_lossless.py --out-dir gate2_lossless
```

[原件与分片 SHA‑256 清单](lossless_parts/MANIFEST.json)。分片只改变仓库传输方式，拼出的 MP4 与机器导出的原件逐字节相同。原件为 H.264 lossless yuv420p；普通手机或网页播放器优先用上面的兼容版。

- 春：卧猫背耳一像素暖缘，尾尖偶摆；路灯下微蛾绕飞。
- 夏：网吧倒影下拆成横向细条，雨滴局部打散倒影；檐滴、逆光坐猫。
- 秋：归鸟分散、一次穿过暮空，右侧树冠遮挡退出；左亭茶汽移到暗木前，向上淡散。
- 冬：5 秒前后只翻一次书页；窗灯、瓦顶小烟和近处路灯下落雪各自运动。
