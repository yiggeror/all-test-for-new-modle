# Gate 2 · 独立复验

四条无损原件均全量解码：各 660 个连续 1/30 秒视频时间点，恰好 22 秒。每季两周期同相位 330 对逐帧等值；第一周期 330 个画格皆不相同，无首尾重帧。全量亮度严格 6×6、色度严格 3×3 恒值块，23 帧 RGB 复抽无破块。稀疏检查的原生到解码 RGB 通道差仅为色彩转换舍入（最多 3 级）。

| 季节 | 跨第 329→330 帧差 / 近邻普通帧差 | 检查重点 |
| --- | ---: | --- |
| 春 | 1.009 | 猫背耳和尾尖、花瓣和灯下飞蛾 |
| 夏 | 0.977 | 雨丝、檐滴、红色湿地横波与猫耳尾 |
| 秋 | 0.986 | 归鸟掠过及入树、茶壶热汽与暖窗 |
| 冬 | 0.994 | 翻页与伏案、屋顶淡烟、暖窗雪 |

帧差比分母用附近正常运动的平均步幅；理想不要求周期最后一帧等于第一帧。这里相同相位指第一周期第 n 帧对第二周期第 n+330 帧。静墙另做分区核查，避开实际经过粒子或灯边界的像素。
