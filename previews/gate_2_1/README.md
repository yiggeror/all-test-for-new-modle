## 直接看与无损核对

上表 MP4 是浏览器／手机可播放的 High Profile 审片副本，来自 6× 最近邻母版，均为 1920×1080、30 fps、660 帧、22 秒。兼容压缩会改变像素；逐像素核验用下方 QP 0 正本。

从仓库根目录运行：

```bash
python previews/gate_2_1/tools/restore_lossless.py --out-dir gate21_lossless
```

[分卷与整片 SHA-256](lossless_parts/MANIFEST.json) 由此命令逐项检查。四条正本完整解码，660 帧均等于原生 320×180 RGB 按 BT.709 6× 最近邻转换的 YUV；第二轮 330 帧与第一轮完全相同，两轮连接没有重复尾帧。详见 [QA 数据和实际动作图](qa/) 与 [总览](qa/overview_1x.png)。

源包：[春、夏](source/spring_summer_gate21_source.zip) · [秋、冬](source/autumn_winter_v21.zip)。每包均写明依赖、实渲命令和运行产物。秋冬直接使用仓库已有 Gate 2 源归档，不依赖私有机器文件。
