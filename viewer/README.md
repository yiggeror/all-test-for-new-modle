# 星野铃 · 3D 检视器

在仓库或解压后的目录运行 `python3 viewer/start.py`。Windows 可以双击 `start-viewer.cmd`，也可以执行 `py -3 viewer/start.py`。浏览器会打开 `http://127.0.0.1:8765/viewer/`；不需要外网。结束时在启动窗口按 Ctrl+C。如果该端口正被使用，添加 `--port 8766`。

- 拖动旋转，滚轮或双指缩放，右键拖动或两指一起移动平移。
- 一键切换全身、半身、脸部特写或背面，再挑选灰模、线框或灯光。
- 可以播放或拖动原连续动作，也可以独立试看四种原生表情。
- 所需文件是 `viewer/` 和 `assets/suzu_final.glb`。脚本、模型、贴图随包提供。
